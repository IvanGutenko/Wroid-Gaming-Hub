# Круговое меню оружия (radial_select) и удерживаемые кнопки

Стабильная версия: тег **`stable-wheel-v4`** (коммит `46014de`), проверена вживую
в Standoff 2. Откат: `git checkout stable-wheel-v4`.

## Присед / удержание (hold)
Действие `"kind": "hold"` в биндинге: палец встаёт на кнопку при нажатии клавиши
и поднимается при отпускании (`reconcile_continuous` сверяет `held_keys`).
Авто-повторы клавиш отфильтрованы на входе (`KeyTransition::Repeated`).

## Круговое меню (radial_select)

Эмуляция жеста «зажми колесо → свайпни в сектор → отпусти» одним нажатием
клавиши.

```json
{
  "input": {"kind": "key", "key": "1"},
  "action": {
    "kind": "radial_select",
    "center": {"x": 0.87, "y": 0.33},
    "distance": 0.07,
    "direction": "down"
  }
}
```

- `center` — точка кнопки колеса (одна и та же для всех секторов!)
- `distance` — длина свайпа, доля короткой стороны экрана
- `direction` — `up | down | left | right`

### Таймированные фазы (критично!)

Жест нельзя отправить одним кадром: Unity/Android схлопывают мгновенные
down→move→up в обычный тап — движения нет, игра «ничего не видит». Фазы
растянуты по времени и управляются тиком сессии (`tick()`, ≤50 мс):

| фаза | действие | задержка |
|---|---|---|
| 1 | Down в центре колеса | держится 60 мс (колесо открывается) |
| 2 | Move к сектору | держится 40 мс |
| 3 | Up в секторе | жест завершён |

Реализация: `PendingRadial` в `game_session.rs`, константы `RADIAL_DOWN_DWELL` /
`RADIAL_MOVE_DWELL`.

### Защита от повторного нажатия

Повторное нажатие клавиши, пока жест летит, раньше начинало второй контакт тем
же id → падение сессии («contact N is already active»). Теперь:
- `cancel_pending_radial(index)` завершает предыдущий жест перед новым;
- сбой фазы не убивает сессию — жест отбрасывается с записью `[radial] ...`
  в лог (`~/.local/state/wroid/game-session.log`).

### Текущий маппинг (Standoff 2)

Все четыре биндинга указывают на один центр; отличается только направление:

| клавиша | направление | оружие |
|---|---|---|
| 1 | down | основное |
| 2 | left | нож |
| 3 | right | пистолет |
| 4 | up | бомба |

## Редактор

- Карточка «Weapon wheel» в Add Control; маркер на канвасе синий, со стрелкой
  направления; инспектор: центр X/Y, дистанция, направление.
- Профиль читается игрой только при старте сессии — после правок перезапускай
  игру (Ctrl+Esc → запуск заново).
